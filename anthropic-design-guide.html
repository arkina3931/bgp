01 — Color System

色彩系统

Anthropic 的调色板以温暖的中性色为基础，通过克制的强调色传递活力感。核心哲学是"少即是多"，背景永远是暖白而非纯白。

05 — Motion

动效原则

悬停上方体验动效。Anthropic 使用 ease-out 曲线（cubic-bezier(0.16, 1, 0.3, 1)）— 快速开始，优雅减速。

→
动效核心规则
Anthropic 的动画设计：克制、有目的、服务于内容。避免跳跳龙式的夸张弹簧效果，偏好线性感强的 ease-out 曲线。页面入场使用 staggered fadeUp（交错延迟 80ms），而非同时出现。

06 — CSS Variables

可直接使用的 CSS 变量

将以下代码复制到你项目的 :root 中即可开始使用 Anthropic 设计语言。

styles/tokens.css 
:root {
  /* ── 品牌核心色 ───────────────────── */
  --color-dark:       #141413;
  --color-light:      #faf9f5;
  --color-mid-gray:   #b0aea5;
  --color-light-gray: #e8e6dc;
  --color-warm-white: #f5f4ef;

  /* ── 强调色 ───────────────────────── */
  --color-orange:     #d97757; /* 主要强调色 */
  --color-blue:       #6a9bcc;
  --color-green:      #788c5d;

  /* ── 字体 ─────────────────────────── */
  --font-display: 'Lora', Georgia, serif;
  --font-body:    'DM Sans', sans-serif;
  --font-mono:    'DM Mono', monospace;

  /* ── 间距（8px 网格）──────────────── */
  --space-1: 4px;   --space-2: 8px;
  --space-3: 12px;  --space-4: 16px;
  --space-5: 24px;  --space-6: 32px;
  --space-7: 48px;  --space-8: 64px;
  --space-9: 96px;

  /* ── 圆角 ─────────────────────────── */
  --radius-sm:   4px;
  --radius-md:   8px;
  --radius-lg:   12px;
  --radius-pill: 999px;

  /* ── 动效 ─────────────────────────── */
  --ease-out:        cubic-bezier(0.16, 1, 0.3, 1);
  --duration-fast:   150ms;
  --duration-normal: 280ms;
  --duration-slow:   500ms;
}

07 — Design Principles

六条核心设计原则

由 Geist 设计工作室为 Anthropic 制定，指导所有视觉决策。

①
暖白而非纯白
背景使用 #faf9f5（暖米白），避免冰冷的纯白。整个品牌调性偏暖。
②
衬线标题 + 无衬线正文
大号标题用 Tiempos（衬线）传递人文温度，正文用 Styrene（无衬线）保持清晰。
③
负字间距 + 斜体
大号标题使用 letter-spacing: -0.02em。斜体用于强调关键词，不用粗体。
④
克制的强调色
橙色 (#d97757) 是唯一主要强调色，仅用于最重要的 CTA 和 Logo 细节。
⑤
模块化网格布局
8px 基础网格，内容区宽度 960px。大量留白，信息密度低，呼吸感强。
⑥
Pill 形状按钮
所有主要按钮使用 border-radius: 999px 的胶囊形，与技术品牌方块风格区分开。
